## Partial rollback without touching code

The new base-window mode is opt-in per request. `bridge_base` defaults to `lfl`,
which reproduces the pre-release MTD bridge exactly (verified below). Dropping the
`Full month` chip is a front-end-only change; the 7D fix is not gated by a flag.

Two independent checks passed:

7-day header. That is the defect this release fixes.
